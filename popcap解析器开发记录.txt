我最早于 2024/06/03 开始开发这个项目。当时的想法是提取出手头的宝石迷阵3和植物大战僵尸游戏中的游戏素材。由于这些游戏都是 popcap 公司做的，因此我的这个项目便叫做 popcap_pak_extractor。这个项目并没有考虑其他公司的 pak 文件的格式问题，这是完全为 popcap 准备的。

我很快在 github 上找到了一个 rust 版本的实现，理解了基本原理后，使用 C++ 做了第一个版本的实现，它工作的不错，但是代码写的相对比较差劲，因此我对其进行了重构，也就是这个目录下现在能看到的版本。

编写 C 版本是为了方便部分只使用 C 的用户，因为有些用户不太喜欢使用 C++(尽管现在的 C++ 版本已经非常易读和易于修改了)。我围绕这个部分做了比较长期的工作，并且在这个过程中使用 C 来反复重构这个项目，以此作为精进自己 C 水平的练手项目，因此这个项目中有很多名字中带有 archive 的C代码，他们都是过往练手的经验积累。最终，在 2025/09/26 的时候，C版本的项目被我彻底改造成了一个库，也就是现在的版本。
